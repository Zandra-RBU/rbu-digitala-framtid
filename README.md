# RBU:s digitala framtid

Strategiskt underlag om RBU:s kommunikations- och digitala utveckling inför kommande kongressperiod. Framtaget september 2026 — ett levande dokument som uppdateras löpande.

## Hur du visar presentationen

Ladda upp alla filer i den här mappen till ett GitHub-repo, aktivera **GitHub Pages** (Settings → Pages → Deploy from branch → main), och besök sedan `https://ditt-användarnamn.github.io/repo-namn/` — `index.html` öppnas automatiskt som startsida.

Du kan också bara dubbelklicka på `index.html` lokalt för att öppna presentationen direkt i webbläsaren, utan att lägga upp den någonstans.

## Struktur

- **`index.html`** — Slide 1, presentationens start
- **`slide-02.html` till `slide-10.html`** — huvudberättelsen, i ordning
- **`appendix.html`** — fördjupningshubben
- **`omrade-a.html`, `omrade-b.html`, `omrade-c.html`, `omrade-d.html`, `omrade-e.html`, `omrade-g.html`** — detaljerade underlag per utvecklingsområde (Grafisk identitet, Medlemssystem, Datadriven marknadsföring, Medlemsresa, AI, Budskapsplattform)
- **`tidsplan.html`** — detaljerad tidsplan
- **`kostnad.html`** — kostnadsöversikt
- **`avslutning.html`** — vad som krävs av förbundet, idébank, motivering till sociala medier

Alla filer är fristående HTML — inga byggverktyg eller beroenden krävs.
